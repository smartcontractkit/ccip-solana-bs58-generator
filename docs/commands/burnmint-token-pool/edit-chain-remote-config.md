# bm edit-chain-remote-config

Replace the whole chain config for one remote chain: remote token, decimals and the full remote pool list.

## Invocation

```bash
cct-solana-tx bm --instruction edit-chain-remote-config --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--program-id` | programId | yes | Burnmint token pool program ID (required for all instructions) |
| `--mint` | mint | yes | Token mint address (required for all instructions) |
| `--authority` | authority | yes | Authority public key (required for all instructions) |
| `--pool-addresses` | json | yes | JSON array of pool addresses for init-chain-remote-config and edit-chain-remote-config (init must be empty; if omitted on edit, existing addresses will be cleared) |
| `--token-address` | address | yes | Remote token address (destination chain) as hex string (required for init/edit-chain-remote-config) |
| `--decimals` | decimals | yes | Remote token decimals 0-255 (destination chain, required for init/edit-chain-remote-config) |
| `--remote-chain-selector` | selector | yes | Remote chain selector (required for set-chain-rate-limit, init-chain-remote-config, edit-chain-remote-config, append-remote-pool-addresses, delete-chain-config and get-chain-config) |

## Failure modes

This is a whole-struct overwrite, not a merge: omitting --pool-addresses silently clears the registered remote pools (the flag defaults to an empty list). Pass the full desired set. See [gotchas](../../gotchas/index.md#init-pool-addresses-empty).
