# bm configure-allow-list

Enable or disable the allow list and add sender addresses to it. The list gates OUTBOUND transfers only.

## Invocation

```bash
cct-solana-tx bm --instruction configure-allow-list --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--program-id` | programId | yes | Burnmint token pool program ID (required for all instructions) |
| `--mint` | mint | yes | Token mint address (required for all instructions) |
| `--authority` | authority | yes | Authority public key (required for all instructions) |
| `--add` | json | yes | JSON array of addresses to add to allow list (required for configure-allow-list) |
| `--enabled` | boolean | yes | Enable or disable allow list (true/false, required for configure-allow-list) |

## Failure modes

Adding an address already present reverts AllowlistKeyAlreadyExisted (6010). Enabled with an empty list blocks every sender (InvalidSender 6006) rather than allowing all. See docs/gotchas.
