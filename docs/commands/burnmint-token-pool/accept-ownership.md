# bm accept-ownership

Accept a pending ownership transfer of the pool. Must be signed by the proposed owner.

## Invocation

```bash
cct-solana-tx bm --instruction accept-ownership --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--program-id` | programId | yes | Burnmint token pool program ID (required for all instructions) |
| `--mint` | mint | yes | Token mint address (required for all instructions) |
| `--authority` | authority | yes | Authority public key (required for all instructions) |

## Failure modes

Anyone other than the proposed owner is rejected with Unauthorized (6002); the outgoing owner cannot self-accept.
