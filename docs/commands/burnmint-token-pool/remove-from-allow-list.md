# bm remove-from-allow-list

Remove sender addresses from the allow list. Does not disable the list.

## Invocation

```bash
cct-solana-tx bm --instruction remove-from-allow-list --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--program-id` | programId | yes | Burnmint token pool program ID (required for all instructions) |
| `--mint` | mint | yes | Token mint address (required for all instructions) |
| `--authority` | authority | yes | Authority public key (required for all instructions) |
| `--remove` | json | yes | JSON array of addresses to remove from allow list (required for remove-from-allow-list) |

## Failure modes

Removing an address that is not present reverts AllowlistKeyDidNotExist (6011). Removing the last entry leaves the list enabled and empty, which blocks all senders.
