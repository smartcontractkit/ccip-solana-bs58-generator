# bm initialize-pool

Create the pool State PDA for a mint, making this program the token's burn/mint pool. The caller becomes the pool owner.

**Preconditions:** The caller must be the mint authority at the time of the call, and the pool program must be deployed with its global config initialized.

## Invocation

```bash
cct-solana-tx bm --instruction initialize-pool --env devnet [flags]
```

## Flags

| `--mint` | mint | yes | Token mint address (required for all instructions) |
