# bm set-chain-rate-limit

Set the inbound and outbound token-bucket rate limits for one remote chain.

**Preconditions:** Capacity and rate are in the LOCAL token's smallest units: multiply by 10^decimals of the mint on this chain, not the remote one. The chain must already be configured with init-chain-remote-config.

## Invocation

```bash
cct-solana-tx bm --instruction set-chain-rate-limit --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--program-id` | programId | yes | Burnmint token pool program ID (required for all instructions) |
| `--mint` | mint | yes | Token mint address (required for all instructions) |
| `--authority` | authority | yes | Authority public key (required for all instructions) |
| `--remote-chain-selector` | selector | yes | Remote chain selector (required for set-chain-rate-limit, init-chain-remote-config, edit-chain-remote-config, append-remote-pool-addresses, delete-chain-config and get-chain-config) |

| `--inbound-rate` | rate | yes | Inbound rate limit refill rate per second in smallest units (ONLY for set-chain-rate-limit) |
| `--outbound-enabled` | enabled | yes | Enable outbound rate limiting (true/false, ONLY for set-chain-rate-limit) |
