# r set-pool

Point the token's registry entry at its pool by registering the address lookup table, activating the token for cross-chain transfers.

**Preconditions:** The lookup table must already contain the canonical account set. Writable indexes are normally [3, 4, 7] (pool state, pool token account, mint).

## Invocation

```bash
cct-solana-tx r --instruction set-pool --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--program-id` | programId | optional | Router program ID (required for most instructions) |
| `--mint` | mint | yes | Token mint address (required for registry instructions, optional for append-to-lookup-table) |
| `--authority` | authority | yes | Authority public key (required for all instructions) |
| `--pool-lookup-table` | pubkey | yes | Pool Address Lookup Table (required for set-pool) |
| `--writable-indexes` | json | yes | JSON array of ALT indexes that must be writable, e.g. '[3,4,7]' (required for set-pool). The program converts them to a bitmap on chain |
