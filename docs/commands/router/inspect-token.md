# r inspect-token

Read-only audit of one token: the mint (authority, freeze authority, SPL multisig members, Token-2022 extensions), the pool state and its token account, the pool program global config, the CCIP token admin registry, and the address lookup table.

**When to use:** Verify a deployment, or hand one over. One command covers the roles that are easy to forget: who can still extend the lookup table the router reads on every send, whether the pool token account carries a delegate, and whether the mint has Token-2022 extensions that change what a transfer does. It does not report the pool program's upgrade authority.

## Invocation

```bash
cct-solana-tx r --instruction inspect-token --env devnet [flags]
```
