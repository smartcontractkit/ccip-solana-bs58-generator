# r owner-override-pending-administrator

Overwrite the pending administrator nomination on a registry entry that has not been accepted yet.

## Invocation

```bash
cct-solana-tx r --instruction owner-override-pending-administrator --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--program-id` | programId | optional | Router program ID (required for most instructions) |
| `--mint` | mint | yes | Token mint address (required for registry instructions, optional for append-to-lookup-table) |
| `--authority` | authority | yes | Authority public key (required for all instructions) |
| `--token-admin-registry-admin` | pubkey | yes | Token Admin Registry administrator to propose/override (required for owner-propose-administrator, owner-override-pending-administrator) |

## Failure modes

Once an administrator has accepted the role the entry is owned and this fails InvalidTokenAdminRegistryProposedAdmin (7022); recover instead with transfer-admin-role followed by accept-admin-role.
