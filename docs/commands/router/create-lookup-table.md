# r create-lookup-table

Create the address lookup table for a token and populate it with the canonical CCIP accounts. Signs and sends with a local keypair (it cannot be executed through a multisig).

## Invocation

```bash
cct-solana-tx r --instruction create-lookup-table --env devnet [flags]
```
