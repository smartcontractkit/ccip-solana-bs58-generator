# u derive-accounts

Derive and display the PDAs and account addresses for a program and mint without sending anything. Useful for obtaining the pool signer PDA before creating the SPL multisig.

## Invocation

```bash
cct-solana-tx u --instruction derive-accounts --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--program-type` | type | optional | Program type (burnmint-token-pool, lockrelease-token-pool, router, spl-token) |
| `--program-id` | programId | optional | Program ID (required for most derivations) |
| `--mint` | mint | optional | Token mint address (required for token-specific derivations) |
| `--pool-program-id` | pubkey | optional | Pool program ID (for router derivations) |
| `--remote-chain-selector` | selector | optional | Remote chain selector (for chain config derivations) |
