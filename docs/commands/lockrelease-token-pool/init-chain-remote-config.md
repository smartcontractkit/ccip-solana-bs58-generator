# lr init-chain-remote-config

Create the chain config account for one remote chain: its token address, that token's decimals, and an initially empty remote pool list.

**When to use:** First-time configuration of a remote chain on the pool. Remote pool addresses MUST be empty at init; append them afterwards with append-remote-pool-addresses.

## Invocation

```bash
cct-solana-tx lr --instruction init-chain-remote-config --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--program-id` | programId | yes | Lockrelease token pool program ID (required for all instructions) |
| `--mint` | mint | yes | Token mint address (required for all instructions) |
| `--authority` | authority | yes | Authority address (required for all instructions) |
| `--pool-addresses` | json | optional | JSON array of pool addresses for init-chain-remote-config and edit-chain-remote-config (init must be empty; if omitted on edit, existing addresses will be cleared) |
| `--token-address` | address | yes | Remote token address (required for init/edit-chain-remote-config) |
| `--decimals` | decimals | yes | Token decimals (required for init/edit-chain-remote-config) |
| `--remote-chain-selector` | selector | yes | Remote chain selector (required for set-chain-rate-limit, init-chain-remote-config, edit-chain-remote-config, append-remote-pool-addresses, delete-chain-config and get-chain-config) |

## Failure modes

Passing a non-empty --pool-addresses at init is rejected. See [gotchas](../../gotchas/index.md#init-pool-addresses-empty).
