# lr set-rebalancer

Set the account allowed to provide and withdraw pool liquidity. Required before any liquidity operation.

## Invocation

```bash
cct-solana-tx lr --instruction set-rebalancer --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--program-id` | programId | yes | Lockrelease token pool program ID (required for all instructions) |
| `--mint` | mint | yes | Token mint address (required for all instructions) |
| `--authority` | authority | yes | Authority address (required for all instructions) |
| `--rebalancer` | rebalancer | yes | Rebalancer address (required for set-rebalancer) |

## Failure modes

With no rebalancer set, provide-liquidity fails Unauthorized (6002).
