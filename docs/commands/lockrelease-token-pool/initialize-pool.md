# lr initialize-pool

Create the pool State PDA for a mint, making this program the token's lock/release pool. The caller becomes the pool owner.

**Preconditions:** The caller must be the mint authority at the time of the call, and the pool program must be deployed with its global config initialized.

## Invocation

```bash
cct-solana-tx lr --instruction initialize-pool --env devnet [flags]
```

| `--mint` | mint | yes | Token mint address (required for all instructions) |
