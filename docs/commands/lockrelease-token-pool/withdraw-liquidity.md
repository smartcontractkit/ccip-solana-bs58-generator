# lr withdraw-liquidity

Withdraw tokens from the pool's token account back to the rebalancer.

**Preconditions:** Requires the rebalancer role and can-accept-liquidity true, but NOT a delegate approval: the pool signer PDA already owns the source account.

## Invocation

```bash
cct-solana-tx lr --instruction withdraw-liquidity --env devnet [flags]
```
