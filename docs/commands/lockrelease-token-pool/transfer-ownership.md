# lr transfer-ownership

Propose a new pool owner. Two-step: the proposed owner must then call accept-ownership.

## Invocation

```bash
cct-solana-tx lr --instruction transfer-ownership --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--program-id` | programId | yes | Lockrelease token pool program ID (required for all instructions) |
| `--mint` | mint | yes | Token mint address (required for all instructions) |
| `--authority` | authority | yes | Authority address (required for all instructions) |
| `--proposed-owner` | proposedOwner | yes | Proposed new owner public key (required for transfer-ownership) |

## Failure modes

Before acceptance the proposal can be redirected by proposing someone else, but not cleared (the zero address is rejected with InvalidInputs 6003). After acceptance there is no cancel or reclaim instruction.
