# spl create-mint

Create an SPL mint under a seed-derived address, optionally with metadata and an initial supply minted to a recipient.

**Preconditions:** Pick the metadata backend with --metadata: 'metaplex' writes a separate Metaplex PDA (either token program), 'token-2022' embeds it in the mint via the TokenMetadata extension and requires --token-program token-2022. --with-metaplex true is an alias for 'metaplex'. The embedded backend is creation-only: Token-2022 extensions are initialized before InitializeMint, so an existing mint can never gain the TokenMetadata extension, whereas Metaplex metadata can be attached later.

## Invocation

```bash
cct-solana-tx spl --instruction create-mint --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--authority` | authority | yes | Payer/authority public key |
| `--recipient` | pubkey | optional | Recipient address (for mint instruction or create-mint initial supply) |
| `--decimals` | number | yes | Token decimals (0-255, required for create-mint) |
| `--token-program` | program | optional | Token program: spl-token or token-2022 (default: spl-token) |
| `--with-metaplex` | boolean | optional | Create with Metaplex metadata (true/false) |
| `--metadata` | backend | optional | Metadata backend for create-mint: none, metaplex (separate PDA, any token program) or token-2022 (embedded in the mint, requires --token-program token-2022). Overrides --with-metaplex |
| `--name` | string | optional | Token name (required if with-metaplex=true, max 32 chars) |
| `--symbol` | string | optional | Token symbol (required if with-metaplex=true, max 10 chars) |
| `--uri` | string | optional | Metadata URI (required if with-metaplex=true) |
| `--initial-supply` | number | optional | Initial supply in smallest units (optional) |

## Failure modes

The backend decides which instruction can later change the metadata authority; see docs/gotchas #metadata-backend-decides-the-instruction. Freeze authority is set to the mint authority. The mint address is random per run (auto-generated seed).
