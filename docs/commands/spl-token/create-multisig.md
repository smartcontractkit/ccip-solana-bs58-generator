# spl create-multisig

Create an SPL token multisig, typically to hold the mint authority with the pool signer PDA as a member.

**Preconditions:** --mint is required to detect the correct token program and --seed to derive the account address.

## Invocation

```bash
cct-solana-tx spl --instruction create-multisig --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--authority` | authority | yes | Payer/authority public key |
| `--mint` | pubkey | yes | Token mint address (required for mint; also used to detect token program for create-multisig) |
| `--signers` | json | yes | JSON array of signer pubkeys (for create-multisig) |
| `--threshold` | m | yes | Threshold (for create-multisig) |
| `--seed` | string | yes | Seed for createAccountWithSeed (required for create-multisig) |

## Failure modes

SPL multisigs are IMMUTABLE: members and threshold cannot be changed afterwards. The token program never checks threshold <= signers, so such a multisig would initialize and be permanently unusable; this CLI refuses it. Max 11 signers. See docs/gotchas #mint-authority-multisig.
