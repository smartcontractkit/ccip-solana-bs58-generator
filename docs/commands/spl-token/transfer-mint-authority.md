# spl transfer-mint-authority

Move the mint authority to a new account, normally an SPL multisig containing the pool signer PDA.

## Invocation

```bash
cct-solana-tx spl --instruction transfer-mint-authority --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--authority` | authority | yes | Payer/authority public key |
| `--mint` | pubkey | yes | Token mint address (required for mint; also used to detect token program for create-multisig) |
| `--new-mint-authority` | pubkey | yes | New mint authority (for transfer-mint-authority) |

## Failure modes

Run the CCIP registry steps first: owner-propose-administrator requires the caller to still be the mint authority.
