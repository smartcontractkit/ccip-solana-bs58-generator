# spl mint

Mint tokens to a recipient. Supports minting through an SPL multisig authority with --multisig and --multisig-signers.

## Invocation

```bash
cct-solana-tx spl --instruction mint --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--authority` | authority | yes | Payer/authority public key |
| `--mint` | pubkey | yes | Token mint address (required for mint; also used to detect token program for create-multisig) |
| `--recipient` | pubkey | yes | Recipient address (for mint instruction or create-mint initial supply) |
| `--amount` | u64 | yes | Amount in smallest unit (for mint) |
| `--multisig` | pubkey | optional | SPL multisig address (optional, for mint) |
| `--multisig-signers` | json | optional | JSON array of signer pubkeys (optional, for mint) |
| `--metadata-account` | pubkey | optional | Explicit metadata account (Token-2022), defaults to mint |
| `--metadata` | backend | optional | Metadata backend for create-mint: none, metaplex (separate PDA, any token program) or token-2022 (embedded in the mint, requires --token-program token-2022). Overrides --with-metaplex |
| `--token-account` | pubkey | optional | Token account to approve from (optional, auto-derives from authority + mint if not provided) |

## Failure modes

Does not create the recipient's associated token account; create it first. A member that is a PDA (such as a Squads vault) cannot sign this way - see docs/gotchas #vault-mint-needs-squads-tx.
