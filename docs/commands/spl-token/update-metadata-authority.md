# spl update-metadata-authority

Update the metadata update authority of a Token-2022 mint that carries the native TokenMetadata extension.

## Invocation

```bash
cct-solana-tx spl --instruction update-metadata-authority --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--authority` | authority | yes | Payer/authority public key |
| `--mint` | pubkey | yes | Token mint address (required for mint; also used to detect token program for create-multisig) |
| `--new-authority` | pubkey | optional | New metadata update authority (for update-metadata-authority). OMITTING THIS REMOVES the authority permanently - it cannot be restored |

## Failure modes

Only applies to metadata embedded in the mint (create-mint --metadata token-2022). Mints whose metadata lives in a Metaplex PDA must use the metaplex update-authority instruction instead. Omitting --new-authority REMOVES the authority irreversibly.
