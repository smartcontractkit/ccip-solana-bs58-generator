# spl approve

Approve delegate command for SPL Token

## Invocation

```bash
cct-solana-tx spl --instruction approve --env devnet [flags]
```

## Flags

| Flag | Arg | Required | Description |
| --- | --- | --- | --- |
| `--authority` | authority | yes | Payer/authority public key |
| `--mint` | pubkey | yes | Token mint address (required for mint; also used to detect token program for create-multisig) |
| `--amount` | u64 | yes | Amount in smallest unit (for mint) |
| `--token-account` | pubkey | optional | Token account to approve from (optional, auto-derives from authority + mint if not provided) |
| `--delegate` | pubkey | yes | Delegate address to approve (required for approve) |
